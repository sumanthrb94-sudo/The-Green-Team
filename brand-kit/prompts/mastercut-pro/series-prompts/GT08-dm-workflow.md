  Run it as the third or fourth post in a thread after GT01–GT07
  have built trust. Do not run as the first impression.
- Beat 1 crown wraps 'AGARTHA' in apostrophes — matches IG comment
  matching behavior. Some keyword-trigger DM apps require exact
  punctuation match.
- For SYL or other future properties, swap only the keyword and the
  brief contents. The architecture stays.
