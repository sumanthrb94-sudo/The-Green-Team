# Post copy — Agartha permaculture campaign

Captions and hashtag sets per film. Same rules as the scripts: no pricing,
no rates, no ROI language, no RERA number, nothing implying the homes are
built and ready. Channel-partner status is disclosed on every post.

The comment word in the caption **must match the outro baked into that
film's cut** (`reel/outros/`) or the CTA contradicts itself on screen.

---

## Film 5 — The forest was there first · outro: FOREST

**Caption:**

```
Most projects clear the forest. Then plant saplings and call it green.

Agartha didn't.

It sits on the Narsapur forest boundary — native dry deciduous woodland that
was standing long before anyone drew a layout. The permaculture design worked
around it instead of over it: paths bend where the trees already were, plots
come pre-planted, and the canopy stayed exactly where it was.

Forty minutes out of Hyderabad. Loudest thing all day is birds.

So — trees, or a forest?

↓ Comment FOREST and we'll send you the walkthrough.
Or DM us to book a site visit and go stand in it yourself.

The Green Team — authorised channel partner for MODCON Agartha, Narsapur.
```

First line is 69 characters, so the hook lands in full before Instagram's
"more" cutoff. That matters more than anything else in the caption.

**Hashtags:**

```
#Agartha #ModconAgartha #TheGreenTeam #Narsapur #NarsapurForest
#HyderabadRealEstate #HyderabadProperty #Telangana #RRRCorridor
#Farmland #FarmlandForSale #FarmPlots #ManagedFarmland #FarmHouseHyderabad
#Permaculture #FoodForest #Agroforestry #RegenerativeLand #EdibleForest
#SustainableLiving #EcoLiving #ForestHomes #GreenLiving
#WeekendHome #SecondHome #NatureLovers
```

26 tags. The mix is deliberate:

| Tier | Purpose |
| --- | --- |
| Brand (`#Agartha`, `#ModconAgartha`, `#TheGreenTeam`) | Own the search, build a searchable body of work |
| Local (`#Narsapur`, `#HyderabadRealEstate`, `#RRRCorridor`) | Where buyers actually are — highest intent |
| Category (`#Farmland`, `#ManagedFarmland`, `#FarmPlots`) | The thing being sold |
| Values (`#Permaculture`, `#FoodForest`, `#Agroforestry`) | Lower volume, far better fit — these bring the people who care about *why* this project is different |
| Lifestyle (`#WeekendHome`, `#NatureLovers`) | Broad reach, weakest intent — keep these last and few |

The permaculture tags are the ones worth watching. They're small, but they
are the only tags on this list where Agartha is genuinely differentiated
rather than one of a thousand farmland listings.

**Alternative hook**, if the first line underperforms — swap only the
opening and leave the rest:

```
Everyone sells you trees. Almost nobody kept the ones that were already there.
```
