Telugu voice agent

Development page. Click the button in the corner and talk — this is the same pipeline that runs on the phone leg, with the browser swapped in for Plivo.

This path never touches a telecom network, so no DLT registration, 140-series number or DND scrub applies. The AI disclosure and DPDP consent still do, and both are in the widget before the mic opens.
  1. Set SARVAM_API_KEY in .env
  2. Run uvicorn agent.server:app --port 8080
  3. Watch the log for time-to-first-audio — the budget is 800 ms

To embed on the live site:

<script src="https://<host>/web/widget.js" data-agent-host="https://<host>" data-project="agartha" data-rera="<reg-no>"></script>
