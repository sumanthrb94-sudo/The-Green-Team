# MODCON SYL Residences — Telugu Video Voiceover

**For:** ElevenLabs TTS · video narration
**Register:** warm, cinematic, unhurried — this is not the sales-call voice. Slower, fewer words, more space.
**Facts:** mirror `SANCTUARIES['syl']` in `src/App.tsx`. If the site changes, change these.

> **The one rule that matters for ElevenLabs:** every number is already written as Telugu words. Do not "fix" them back to digits — `₹4,499` comes out as English digits or garbled Telugu. This is the single most common failure on Indic TTS.

## ElevenLabs settings

| Setting | Value | Why |
|---|---|---|
| Model | **Multilingual v2** | Telugu is supported and stable here. v3 adds audio tags but its Indic prosody is still uneven — test before switching. |
| Stability | **0.50** | Narration wants consistency. The 0.45 used for the sales script is too loose for voiceover. |
| Similarity | **0.85** | |
| Style | **0.15** | Low. Style exaggeration is what makes Indic TTS sing-song. |
| Speaker boost | on | |
| Speed | **0.95** | Slightly under normal. This is a film, not a call. |

**`<break time="..."/>` is honoured by ElevenLabs** and is doing real work here — the pauses are the pacing of the film. Don't strip them.

If a line comes out rushed, add breath by splitting it into two generations and butting them together in the edit, rather than raising stability — that flattens the delivery.

---

## Before you render

1. **Numbers stay as words.** If you edit any line, write new numbers out in Telugu too. `4,499` will not survive.
2. **Render each section separately.** Six clean takes cut better than one 60-second take with one bad word in the middle.
3. **Listen on a phone speaker.** Most of this will be watched on one.
4. **Brand names:** మోడ్‌కాన్ (not "mod-con"), ఎస్. వై. ఎల్. spelled as letters, తుక్కుగూడ with the retroflex ట్ట.
